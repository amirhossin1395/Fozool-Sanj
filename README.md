## 🎯 درباره پروژه

**فضول سنج** یه وب‌اپلیکیشن **سرگرم‌کننده و شوخ‌طبعانه** است که با استفاده از دوربین یا آپلود عکس، یه درصد تصادفی (۱ تا ۱۰۰) به عنوان «میزان فضولی» به کاربر می‌ده! 😂

> ⚠️ **توجه:** این سایت فقط جنبه **سرگرمی** داره و هیچ تحلیل واقعی، پردازش تصویر یا هوش مصنوعی انجام نمی‌ده. درصدها کاملاً تصادفی هستن. 😄

### 💡 چرا این پروژه؟

- 🎉 یه پروژه **سبک، شاد و وایرال‌پذیر**
- 🎨 گرافیک **مدرن و جذاب** با تم سبز شاد
- 📱 کاملاً **ریسپانسیو** (موبایل، تبلت، دسکتاپ)
- 🚀 آماده برای **دیپلوی روی Render، Vercel، Netlify یا GitHub Pages**

- وب‌کم (برای حالت اسکن زنده) — اختیاری

### 🔧 اجرای محلی

```bash
# ۱. کلون کردن ریپازیتوری
git clone https://github.com/amirhossin1395/Fozool-Sanj.git

# ۲. ورود به پوشه پروژه
cd Fozool-Sanj

# ۳. اجرای پروژه (یکی از این روش‌ها)

# روش ۱: باز کردن مستقیم
# فایل index.html رو توی مرورگر باز کن

# روش ۲: با Live Server (VS Code)
# راست کلیک روی index.html → Open with Live Server

# روش ۳: با Python
python -m http.server 8000
# سپس باز کن: http://localhost:8000
